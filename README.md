# Email Spam Detection

## Objective
The objective of this project is to classify SMS/Email messages as Spam or Ham using Machine Learning.

## Dataset
- SMS Spam Collection Dataset

## Technologies Used
- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Scikit-learn

## Machine Learning Model
- Multinomial Naive Bayes

## Result
- Accuracy: 96%
